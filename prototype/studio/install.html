This fork-only prototype includes a local demo studio and an unpacked Chrome extension. They share the same general-flash detector.

Install the extension

  1. Download the prototype ZIP and extract it, or use the prototype/extension directory in the fork.
  2. Open chrome://extensions in Chrome or Chromium.
  3. Enable Developer mode, choose Load unpacked, then select the extension folder.
  4. Open a source fixture and choose Start. Keep the initial guard enabled. The extension popup shows local events.

The extension needs access to HTTP/HTTPS page content to inspect it. Events store hostnames only, locally, with a bounded log. There is no reporting server.

Research that informed the build

W3C general-flash definition informed luminance and opposing-transition counting. The area calculation here is a prototype heuristic, not a visual-field calibration. Red-flash analysis is not implemented.

Chrome content scripts informed the isolated-world extension design. No remote scripts, page-message bridge, accounts, or analytics are used.

MDN video frame callbacks informed per-frame video sampling. Canvas origin restrictions informed fail-closed handling. The studio demonstrates a real cross-origin pixel-read failure.

Known boundaries

This is not a medical device or guaranteed protection. Initial page rendering, browser scheduling, source size, overlays, and unsupported media can affect outcomes. No DRM or animated image decoding, red-flash detection, viewport area aggregation, adversarial-page hardening, Firefox/Safari extension support, or formal WCAG certification is claimed.

The studio’s covered test source is deliberately controlled. A passing fixture does not establish safety on arbitrary websites.

Run and test locally

node prototype/server.mjs starts the studio at http://127.0.0.1:8787. The adjacent local port serves the cross-origin fixture.

node --test prototype/test/*.test.mjs demo/test/*.mjs runs unit tests. Browser checks and video production instructions are in the prototype README.
